# Data availability

## TN monitoring observations

TN monitoring observations were obtained from the China National Environmental Monitoring Centre (CNEMC; https://www.cnemc.cn). These data are subject to access restrictions and are not redistributed in this repository. Interested researchers should consult CNEMC regarding applicable access conditions. A third-party application route has not been confirmed.

Restrictions may also apply to cleaned records, aggregated observations, merged tables, trained models and derived outputs. Such materials are not included without permission to redistribute them.

## Environmental and geospatial inputs

The study uses climatic data, land cover, lake-basin topology, human footprint and lake surface extent from their respective original providers. The manuscript identifies the following sources:

| Category | Source description |
| --- | --- |
| Climate | 1 km monthly China temperature and precipitation; National Earth System Science Data Center |
| Land cover | 30 m annual land-cover data for China |
| Basin boundaries | Lake-TopoCat drainage topology and basin database |
| Human activity | 1 km Global Human Footprint data |
| Lake surface area | Monthly 30 m global lake surface extent data |

Refer to the manuscript and its supplementary material for source citations. Exact product identifiers and download links are not supplied in this code release. Obtain source datasets under their providers' access and use terms; public accessibility does not imply unrestricted redistribution.

## Code sharing

This repository provides analysis code and input specifications. It does not contain original or processed TN observations, merged study tables or study outputs. Reproducing observation-based analyses requires authorized access to the monitoring observations and prepared environmental inputs. The code license does not override third-party data restrictions.
